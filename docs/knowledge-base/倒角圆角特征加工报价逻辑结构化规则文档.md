# 倒角/圆角特征加工报价逻辑结构化规则文档（v1 · 待业务审冻）

> **v1 draft-for-freeze｜2026-09-12｜待业务审冻**
>
> - 本文只定义独立边特征 `chamfer` / `fillet` 的最小业务口径，不是可执行规则。
> - 独立边倒角是几何尺寸 **C** 的边倒角；独立边圆角是几何尺寸 **R** 的边圆角。
> - 现有特征工艺链末端的 `process: chamfer` /「倒角」是工序步骤，不属于本文对象，其识别、展开、排序、合并和报价路径全部保持不变。
> - 在后续 wiring PR 通过业务门禁前，独立 `chamfer` / `fillet` 必须在审核树中保持隐藏。
> - 在切削参数、刀具和工时边界表齐备前，独立 `chamfer` / `fillet` 必须为 `quote_excluded`、金额为 0，且不得进入工序费用合计。
> - 无已审定独立工艺链，禁止自动展开计时；禁止用其他特征或现有链末倒角的参数拼出临时公式。

## 1. 文档边界

本文冻结倒角/圆角独立边特征从识别语义到报价阻断的最小结构，供后续规则表建设和 wiring PR 使用。业务将在本文合并、抽样后审冻；当前状态是“待业务审冻”。

v1 范围：

- 对象：作为独立几何特征表达的边倒角 `chamfer`（C）和边圆角 `fillet`（R）。
- 目标：明确识别边界、树隐藏规则、报价排除规则及允许自动报价前必须关闭的 gaps。
- 工艺：只记录加工意图，不冻结独立工艺链、刀路、工时公式或参数值。
- 输出：只允许形成待审/阻断语义；不得形成可计价工时。

明确不在本文范围：

- 既有孔、槽/型腔、螺纹、面、台阶等特征链末端的 `process: chamfer` /「倒角」工步。
- 特征树露出、gaps 代码骨架、独立特征自动计时或自动计价。
- 外圆定价、2D/PDF、流程图 phase 2。
- 任何报价公式、规则 YAML、刀具库、工厂配置、前后端运行时代码或报价 pins。

## 2. 识别定义：边特征与工序步骤严格分离

| 语义 | 身份 | 最小几何含义 | v1 处理 |
| --- | --- | --- | --- |
| 独立边倒角 | `type: chamfer` 特征 | 原始边被斜面替代，核心尺寸语义为 C；具体 C 制式尚待 schema 冻结 | 可作为候选识别结果保留在数据链上，但审核树隐藏、报价排除 |
| 独立边圆角 | `type: fillet` 特征 | 原始边被圆弧/环面过渡替代，核心尺寸语义为 R | 可作为候选识别结果保留在数据链上，但审核树隐藏、报价排除 |
| 链末倒角 | `process: chamfer` 工序步骤，显示名通常为「倒角」 | 某个孔、槽/型腔、螺纹、面或台阶加工链的收尾工序 | 完全沿用现有路径；本文不重定义、不迁移、不合并 |

边界约束：

1. `type: chamfer` 与 `process: chamfer` 不是同一层级：前者是待接线的独立几何特征，后者是已存在的工艺步骤。
2. `type: fillet` 不等同于槽端圆弧、槽/型腔内部角半径或曲面特征；拓扑归属未判定时只能保留人工分类警告。
3. 锥面不必然是边倒角，环面不必然是边圆角。沉头、锥面、环形槽及其他旋转特征必须先完成分类，禁止仅按面型直接自动计价。
4. 不得把独立 `chamfer` / `fillet` 注入既有链末倒角步骤，也不得用既有 `process: chamfer` 的结果反推独立边特征已经获得报价能力。

## 3. 现有系统锚点

| 锚点 | 当前语义 | v1 约束 |
| --- | --- | --- |
| STEP 候选识别 | `backend/cncflow_core/ingestion/step_parser.py` 可产出 `type: chamfer` 的锥面候选和 `type: fillet` 的环面候选，并附带人工分类警告 | 候选不等于已审定独立特征；不得去掉歧义门禁 |
| 后端审核过滤 | `backend/cncflow_core/inquiries/api.py::_REVIEW_FEATURE_TYPES` 不包含 `chamfer` / `fillet`，未映射类型由审核特征清洗逻辑过滤 | 保持隐藏；本 PR 不加类型、不加报价骨架 |
| 前端审核树 | `frontend/src/components/FeatureReview.tsx::REVIEW_TREE_FEATURE_TYPES` 不包含 `chamfer` / `fillet`，`isReviewTreeFeature` 只展示已映射类型 | 保持隐藏；树露出只能在后续独立 wiring PR 讨论 |
| 既有工艺链 | 孔链通过 `chamfer_always` 追加入口/出口或单面倒角；槽腔、面、螺纹、台阶管线也会追加 `process: chamfer` | 路径冻结不变；本文不修改其触发、刀具、工时或金额 |
| 工序排序与合并 | `quoting/sequence.py` 将倒角放在同组末尾；`quoting/dedup.py::merge_chamfers` 按装夹组合并链末倒角；D6 检查“倒角最后” | 继续只服务现有工序步骤；不得自动套用于独立边特征 |

该姿态与外圆在正式树接线前的原则一致：先冻结业务口径和缺口，再单独接线；未过门禁前不因解析器存在候选类型就对用户露出或进入报价。

## 4. 输入与输出

### 4.1 独立特征所需输入

以下是未来接线所需的结构类别，不代表字段名已经审定：

| 类别 | 必需语义 | 当前处理 |
| --- | --- | --- |
| 身份 | 稳定 feature ID、`chamfer` / `fillet` 类型、来源及识别置信/警告 | schema 未审定，阻断自动报价 |
| 拓扑 | 所属实体、原始边、相邻面、内/外边、凸/凹、连续边链及实例数量 | 缺失或归属冲突时转人工 |
| 倒角尺寸 | C 的定义制式、数值、单位、角度或双边尺寸，以及公差 | 未统一前不得把单个长度猜成 C |
| 圆角尺寸 | R、单位、公差及圆弧/环面有效范围 | 未统一前不得按面半径直接报价 |
| 加工可达性 | 加工侧、刀轴方向、干涉、边段长度、入口/退刀空间 | 缺失时阻断自动工艺展开 |
| 材料与质量 | 材料组、热处理、表面要求 | 缺表时阻断自动计时、计价 |
| 报价上下文 | 数量/批量、工厂、候选设备、装夹归属 | 缺失时阻断自动计价 |
| 规则表 | 独立边特征刀具/SKU、切削参数或审定时间模型、工时上下限、夹具影响规则 | 任一必要表缺失即阻断 |

### 4.2 v1 允许输出

独立 `chamfer` / `fillet` 一旦出现在后续数据链中，v1 只允许输出：

1. 特征身份、候选几何尺寸、拓扑归属及识别警告。
2. `quote_status`：明确表示待业务审定或缺表阻断。
3. `quote_excluded: true`。
4. `amount_contribution: 0`；若存在工步形态，工步 `amount` 也必须为 0。
5. 可追溯的 gaps 列表。

这些特征及其任何未审定工步的金额和分钟数均不得进入 process totals、特征加工费或报价总计。隐藏不等于可静默计价；被过滤出审核树的候选同样不得在后台贡献金额。

## 5. 加工意图与最小工艺链

v1 仅保留以下结构性意图：

- `chamfer`：可能需要边倒角加工，但刀具类型、刀路、走刀次数和参数尚未审定。
- `fillet`：可能需要圆角成形加工，但立铣、圆角铣刀、球刀或其他路线的选择尚未审定。
- 识别结果只说明成品几何，不自动决定制造路线。

**v1 无已审定独立工艺链，禁止自动展开计时。**

因此不得生成“倒角加工”“圆角加工”等带分钟数的占位工步，不得把链末 `process: chamfer` 复制为独立特征工步，也不得把独立边特征与既有链末倒角静默合并。是否合并、何时合并以及合并后的换刀/装夹/数量口径，必须由后续业务规则明确。

## 6. 报价规则：缺表即排除

独立倒角/圆角没有获准使用的自动报价公式。以下规则同时成立：

- 没有匹配的切削/刀具参数表和工时上下限表时，必须 `quote_excluded: true`。
- 金额必须为 0，不得进入工序费用合计。
- 不得从 C、R、边长或面面积直接构造经验分钟数。
- 不得复用孔、槽腔、面、螺纹、台阶链末 `process: chamfer` 的时间或 SKU 匹配结果。
- 不得使用默认 `Vc / f / ap`、默认走刀次数、默认刀径、默认换刀时间或其他 fallback 放行。
- 工厂费率或现有刀具记录存在，不代表独立边特征已具备可报价工时。

缺数据时正确输出是显式阻断，而不是“低置信度金额”或临时公式。

## 7. 自动定价前的 blocking gaps

以下缺口全部关闭并通过业务门禁前，不允许自动定价：

1. **独立特征 schema**
   - 冻结 `chamfer` / `fillet` 的稳定字段、版本和来源。
   - 冻结 C 的表达方式（等边 C、距离×角度、双距离等）及 R 的表达方式、单位、公差。
   - 覆盖所属边、相邻面、内外/凸凹、连续边链、数量、加工侧和方向。
2. **识别与归属规则**
   - 区分边倒角与沉头/锥面，区分边圆角与环形槽、槽端圆弧、型腔内角及一般曲面。
   - 定义重复面、连续边段、跨面边链的去重及计数口径。
   - 定义识别置信、人工分类和不可判定状态。
3. **边倒角与边圆角刀具/SKU 表**
   - 分别建立倒角刀及适用的圆角铣刀/球刀/成形刀路线与 SKU 能力表。
   - 至少覆盖材料、C/R 范围、角度、刀径/刃形、有效刃长、可达性、设备和禁用条件。
   - 现有通用倒角刀或“圆角立铣刀”记录不得在缺少独立边特征匹配规则时直接放行。
4. **切削参数或审定时间模型**
   - 按材料、刀具族、工艺路线、尺寸带和设备建立经业务审定的进给/速度/切深或其他时间输入。
   - 明确有效路径长度、切入切出、走刀次数、换刀、测量和批量摊销口径。
   - 本文不提供、也不授权任何 `Vc / f / ap` 数值。
5. **逐工步工时上下限**
   - 为边倒角和边圆角分别定义 `t_min` / `t_max` 的匹配键、版本和缺表行为。
   - 找不到边界必须阻断，不得使用全局默认值。
6. **与既有链末倒角的关系**
   - 决定独立边倒角何时保留为独立工步、何时可与链末 `process: chamfer` 合并。
   - 明确去重键、装夹边界、换刀计费、数量和 `merged_from` 追溯规则。
   - 该规则审定前禁止自动合并。
7. **装夹与设备影响**
   - 明确加工侧/刀轴方向、翻面或新增装夹、干涉、可达性和夹具限制。
   - 明确装夹变化对 setup、设备选择及费率的影响；缺失时转人工。
8. **报价、防错与风险门禁**
   - 定义 `quote_excluded` 到 process totals 的硬隔离、缺表状态、参数合法性、路线一致性和顺序检查。
   - 补齐规则命中来源、版本追溯及“不贡献金额”的回归测试。

下一批次可讨论“树露出 + gaps 骨架”；本 PR 不落任何代码骨架。

## 8. 后续 wiring 门禁

后续 wiring PR 至少必须满足：

- 本文通过业务审冻，独立特征 schema 和识别归属规则已冻结。
- 刀具/SKU、切削或时间参数、工时上下限、装夹/设备规则均可版本化且可审计。
- 无匹配规则时 fail closed，保持 `quote_excluded`、金额 0，并从所有 process totals 排除。
- 独立特征与链末 `process: chamfer` 的合并策略已经单独审定并具备追溯测试。
- 审核树的标签、尺寸展示、选中行为和歧义提示已验收。
- 报价、防错、风险、排序、去重和 pins 回归测试通过。

树露出与 gaps 骨架应作为后续独立变更评审，不得借本文合并而视为获准实施。
