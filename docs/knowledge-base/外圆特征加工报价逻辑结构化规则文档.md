# 外圆特征加工报价逻辑结构化规则文档（v1 · 业务已审冻）

> **冻结状态｜2026-09-12**
>
> - v1 最小工艺链：**外圆粗车 + 外圆精车**。
> - 工时只冻结结构：`t ≈ L_cut / (n · f)`，并要求逐工步校验工时上下限。
> - 在车削 `Vc / f / ap` 表及径向余量表齐备前，**禁止自动计时、禁止自动计价**。
> - 铣削外圆没有已审定参数表，**禁止自动计时**。
> - 外圆特征树在独立 wiring PR 完成前保持隐藏。
> - 禁止拿孔、铣面、台阶或经验常数拼出“临时公式”；缺表就显式阻断，不造数。

## 1. 文档边界

本文冻结外圆特征从业务意图到报价输出的逻辑结构，供后续规则表建设和 wiring PR 使用。本文不是可执行规则，不改变现有报价结果、报价 pins、特征树或任何生产配置。

v1 范围：

- 对象：完整或局部的实体外圆柱加工特征（OD），不是内孔。
- 主路径：车削意图。
- 最小工艺链：外圆粗车 → 外圆精车。
- 暂不纳入：外圆磨削自动链；待后续版本补充。
- 明确禁用：缺参数时自动估时、自动计价；铣削外圆自动估时。

## 2. 现有系统锚点

后续接线必须复用现有系统语义，但不得把“已有模块”误当成“外圆规则已经齐备”。

| 锚点 | 当前语义 | 外圆接线约束 |
| --- | --- | --- |
| 防错 | `backend/cncflow_core/quoting/engine.py::_validation` 收集工步的 `status`、`t_min`、`t_max` | 外圆每个有效工步必须带可追溯上下限；缺上下限表时不得伪装为 `ok` |
| 风险评估 | `backend/cncflow_core/quoting/risk_dimensions.py` 提供 D1 工时下限、D4 设备匹配、D5 `n/f` 合法性、D6 工序顺序、D8 路线一致性、D9 缺失门禁等语义 | wiring PR 应复用相同维度，不另造平行风险体系；表缺失首先是报价阻断，不得只扣分后继续出价 |
| 费率 | 工厂 `rate_table` 按设备类型提供小时费率、setup 费和编程费率 | 费率只能乘以已审定工时；费率存在不代表允许用经验工时出价 |
| 设备库 | `backend/cncflow_core/factory/defaults.py` 已有 CNC 车、车铣复合中心和外圆磨床记录 | 后续按加工意图及设备能力选型；现有 `quoting/equipment.py` 的包络主路径偏铣削，不能未经接线直接宣称支持外圆 |
| 工序排序 | `backend/cncflow_core/quoting/sequence.py` 冻结同一装夹组内“粗 → 半精 → 精”，倒角最后 | v1 外圆链必须保持粗车早于精车；在排序器正式认识外圆工步前，不注入生产路线 |

几何识别已有 `outer_cylinder` 语义，并明确“外圆，不进孔工序链”。它只是识别锚点，不构成可报价工艺链。

## 3. 输入与输出

### 3.1 必需输入

| 类别 | 输入 | 用途 | 缺失处理 |
| --- | --- | --- | --- |
| 几何 | 成品外径 `D_finish`、有效轴向加工长度、轴线/方向 | 明确 OD 与基础切削行程 | 阻断自动报价 |
| 毛坯/余量 | 毛坯外径或经业务表确定的径向余量 | 推导粗车去除量和走刀次数 | 阻断自动计时、计价 |
| 材料 | 可映射到车削参数表的材料组 | 查询 `Vc / f / ap` | 阻断自动计时、计价 |
| 质量 | 尺寸公差、表面粗糙度及其他特殊要求 | 选择精车参数，并判断是否需后续磨削评审 | 无法确认时转人工 |
| 形态 | 连续/断续外圆、台阶、槽、偏心、非回转轮廓等事实 | 判定车削或铣削意图及装夹风险 | 无法判定时转人工 |
| 报价 | 数量/批量、工厂、候选设备 | 设备匹配、setup 摊销和费率追溯 | 阻断自动计价 |
| 规则表 | 车削参数、径向余量、工时上下限、夹具和刀具表 | 形成可审计工艺链 | 任一必需表缺失即阻断 |

### 3.2 目标输出

规则齐备且通过门禁后，外圆模块才允许输出：

1. 加工意图及理由：车削、铣削人工评审，或阻断。
2. 最小工艺链及顺序：外圆粗车 → 外圆精车。
3. 每道工步的参数来源、`L_cut`、`n`、`f`、走刀次数、切削时间和上下限状态。
4. 设备匹配结果、设备能力来源和费率来源。
5. 装夹、刀具及人工复核项。
6. 可报价状态或明确的阻断原因。

在阻断项未清零前，不得输出外圆加工费，也不得让外圆工时进入总价。

## 4. 车削与铣削：加工意图，不是硬阈值

v1 不冻结任何“直径大于/长径比小于某值就车，否则就铣”的数值阈值。

- 几何围绕同一轴线回转、外圆连续且可形成稳定装夹时，标记为**车削意图**。
- 存在偏心、明显非回转轮廓、断续切削、干涉或车床不可达区域时，标记为**需铣削/复合加工评审**。
- 设备行程、回转直径、车削长度、转速、功率和装夹能力只用于能力校验，不单独替代工艺判断。
- “车削意图”不等于已经可计时；仍须通过参数表、余量、夹具、刀具和时间边界门禁。
- 铣削外圆 v1 没有已审定工时表，只能转人工，不能套用台阶铣、轮廓铣或孔加工时间。

## 5. v1 最小工艺链

| 顺序 | 工步 | 目的 | v1 状态 |
| --- | --- | --- | --- |
| 1 | 外圆粗车 | 去除主要径向余量，为精车保留审定余量 | 冻结为必需 |
| 2 | 外圆精车 | 达到成品外径、尺寸公差和表面要求 | 冻结为必需 |
| 后续 | 外圆磨削 | 面向精度、粗糙度或材料状态超出精车能力的场景 | v1 不自动展开，后续版本补表、补链 |

约束：

- 粗车和精车必须是两个独立、可追溯工步，不得合并成一个“车外圆”经验工时。
- 粗车必须早于精车；若需要多次粗车，其次数来自径向余量与审定 `ap`，不得写死。
- 精车留量来自径向余量/工艺余量表，不得由代码常量猜测。
- 一旦质量要求可能触发磨削，v1 只输出人工评审，不自动把磨削费加进报价。

## 6. 工时结构与上下限

### 6.1 物理口径

单次轴向走刀的冻结结构为：

`t_cut ≈ L_cut / (n · f)`

统一口径：

- `t_cut`：单次有效切削时间，单位 min。
- `L_cut`：有效切削行程，单位 mm；应由加工长度、切入、切出和必要越程构成。切入/切出值尚未冻结，不能擅加经验常数。
- `n`：主轴转速，单位 r/min；由材料—刀具—工步对应的审定 `Vc` 与实际切削直径推导，并受设备上限约束。
- `f`：每转进给，单位 mm/r；必须来自审定车削参数表。
- 多次走刀的总切削时间为逐次走刀时间之和；走刀次数依赖径向余量和审定 `ap`。
- 换刀、快速移动、装夹、测量、setup 等不属于上述 `t_cut`，必须各自有独立、可审计口径后才能计入。

这里冻结的是量纲正确的结构，不是完整报价公式。当前缺少 `Vc / f / ap`、径向余量、切入切出以及夹具/刀具规则，不能据此生成生产工时。

### 6.2 工时上下限表

外圆工时边界必须按工步独立配置，不共享一个总时间边界：

| 工步 | 边界键至少包含 | `t_min` | `t_max` | 当前结论 |
| --- | --- | --- | --- | --- |
| 外圆粗车 | 材料组、直径带、长度带、余量带、连续/断续、设备类型 | 待业务表 | 待业务表 | 缺表，阻断自动计时 |
| 外圆精车 | 材料组、直径带、长度带、公差/粗糙度带、设备类型 | 待业务表 | 待业务表 | 缺表，阻断自动计时 |
| 铣削外圆 | 加工形态、材料组、刀具、切深/步距、设备类型 | 待业务表 | 待业务表 | v1 禁止自动计时 |
| 外圆磨削 | 材料/热处理、直径带、长度带、余量、精度/粗糙度、设备类型 | 待后续版本 | 待后续版本 | v1 不进入自动链 |

边界判定语义：

- 计算时间低于 `t_min`：标记“低于下限”，进入防错与 D1 风险。
- 位于上下限内：仅表示时间边界通过，不代表其他门禁通过。
- 高于 `t_max`：标记“需人工复核”。
- 找不到匹配边界：阻断自动计时、计价；不得以默认上下限放行。

## 7. 参数、余量、夹具和刀具缺口

以下四类是明确的 blocking gaps：

1. **车削 `Vc / f / ap` 表**
   - 至少区分材料组、粗车/精车、刀具材料或刀片族、直径/工况带。
   - 要有版本、来源、适用范围和设备约束。
2. **径向余量表**
   - 至少给出毛坯类型/尺寸带到总径向余量、粗车分配、精车留量的映射。
   - 没有该表就无法确定去除量和走刀次数。
3. **夹具表与刀具表**
   - 夹具至少覆盖装夹方式、可夹持范围、装夹次数、找正/翻面及禁用条件。
   - 刀具至少覆盖粗车刀、精车刀、适用材料、刀尖/刀片族、能力范围和换刀口径。
4. **铣削外圆参数/工时表**
   - 在轮廓路径、刀具、切深、步距和边界经业务审定前，铣削外圆只允许人工评审。

此外，切入/切出、测量、换刀、快速移动、setup 及断续切削修正尚无本特征的冻结口径；后续不得把其他特征常数直接搬入。

## 8. Wiring 约束

后续 wiring PR 必须同时满足：

- 所有规则放入可版本化、可审计的规则表；本文只做语义说明，不承载生产阈值。
- 只有当最小工艺链、参数、余量、边界、设备、夹具和刀具均命中时，才允许外圆自动计时。
- 自动计价还必须命中工厂费率；“有费率、无可信工时”仍然阻断。
- 外圆工步接入现有排序、防错和 D1–D9 风险语义，并补齐粗车早于精车、`n/f > 0`、设备匹配和路线一致性测试。
- 规则命中过程必须回传版本和来源，禁止静默 fallback 到经验常数。
- 铣削外圆维持人工路径，直到独立参数/工时表通过业务评审。
- 外圆磨削不在 v1 自动链中，不因设备库存在“外圆磨床”就自动追加。
- 外圆特征树在 wiring PR 完成且验收前保持隐藏。
- wiring PR 不得改动既有 quote pins；任何 pin 变化须单独业务评审。

建议接线顺序：先补规则表与表校验，再接工艺链和工时，随后接设备/费率、防错/风险，最后才开放特征树。任一阶段缺表都应 fail closed。
